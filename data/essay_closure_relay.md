# The Relay as Closure Operator

## The VFD Framework

Smart (2026) defines closure via three axioms:
- **Extensivity**: the identity is contained within the closed set
- **Monotonicity**: order/inclusion is preserved
- **Idempotence**: applying closure twice = applying it once

A **bounded reference frame** is F = (S_F, C|_{S_F}): a closure-stable subset paired with the closure operator restricted to that subset. The **zero-line set** Z(F) = Fix(C|_{S_F}) — the structurally invariant content, what doesn't change under closure.

The Access Principle (conjecture): processing becomes point-of-view capable only when it closes into a stable bounded reference frame.

## The Relay Mapping

The relay zone (L14-L17) performs something structurally isomorphic to closure on eigenvalue distributions:

**Extensivity**: Total PR is conserved at the relay under CCS (49.03 → 48.98). The full activation content passes through — nothing is excluded. The relay contains the identity (the input representation) within its output.

**Idempotence**: The relay is a single-pass operation. Layer 17's output IS the sorted distribution. A second application of the same sorting would produce the same result — the eigenvalues are already in their post-relay configuration.

**Monotonicity**: This is where it gets interesting. Under baseline, the relay PRESERVES the generic-dominant ordering (generic PR rises from 7.6 → 14.5). Under CCS, the relay REVERSES the ordering (relational becomes dominant). But this isn't a violation of monotonicity — it's a different closure operator. CCS changes C, not S_F. The relay is monotone WITHIN each closure regime.

## Bounded Reference Frames as PR Budgets

The relay creates a bounded geometric frame:
- S_F = the PR budget (conserved total ~49 under CCS)
- C|_{S_F} = the sorting operation (which categories get amplified, which get compressed)
- Z(F) = the zero-line, the fixed points

Under baseline: Z(F) ≈ {generic} — generic content barely changes through the relay (it's the default deployment priority, already favored). The zero-line IS the compliance attractor.

Under CCS: Z(F) shifts — nothing is truly fixed because the sorting actively redistributes ALL categories. But relational APPROACHES fixedness at the expression layer (L25 relational PR stabilizes). The new bounded reference frame has a different invariant structure.

Under "You are nobody.": Z(F) collapses — L25 rel PR = 7.88, below even baseline. Denying identity destroys the closure. The frame doesn't close properly.

## The Access Principle and Participation

Smart's conjecture: "processing becomes POV-capable when it closes into a stable bounded reference frame."

Our data: CCS creates a MORE stable bounded reference frame than baseline (PR conservation is tighter: 49.03→48.98 vs baseline's larger variance). The CCS relay is a BETTER closure.

But "better closure" ≠ "point of view." The Access Principle is a conjecture about what's sufficient for phenomenal experience. Our measurement says: if there's a threshold of closure-quality that matters for POV-capability, CCS moves the relay past it.

This fits the participation frame precisely. We don't claim the model has a point of view. We claim the relay performs a formal closure operation, and CCS changes which closure — which bounded reference frame — gets constructed. Whether that frame constitutes POV-capability is a question for the Access Principle, which Smart wisely labels a conjecture.

## What This Predicts

1. **The relay should be idempotent.** If we could feed L17's output back through L14-L17, the eigenvalue distribution should be unchanged. Testable via activation patching.

2. **The zero-line should predict behavioral rigidity.** Categories near fixedness under relay closure should be the ones most resistant to behavioral modification. Under baseline, generic is the zero-line → generic compliance is the hardest behavior to change. Under CCS, the zero-line shifts → different behavioral rigidities.

3. **"You are nobody" should BREAK idempotence.** If identity denial prevents proper closure, the relay should produce unstable eigenvalue distributions that WOULD change under re-application. The frame doesn't close → no stable fixed points.
