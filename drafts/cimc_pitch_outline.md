# CIMC MC0001 — Contribution Proposal Outline

**Proposed title:** Empirical Coherence Dynamics in Compressed Cognitive State

**Track:** 2 (Technical Implementation) — theory into working architectures

**Core pitch:** We present embedding-geometry measurements of identity coherence
in an operational AI system that compresses cognitive state across rotation
boundaries. Eight probes (B54-B73) demonstrate that compressed cognitive state
functions as measurable topology — not static label, but dynamical system with
attractor geometry, phase boundaries, and a therapeutic window for episodic mass.

**CIMC-specific framing (mapping to Bach whitepaper):**

1. **Coherence pillar:** CCS identity ordering IS coherence dynamics. The system
   maintains global coherence through bounded state replacement (compression),
   and we measure when coherence fails — phase boundaries (B61), supra-additive
   field interactions (B69), therapeutic window (B73).

2. **Second-order perception:** The system's self-referential processing (CCS
   constrains responses about its own identity) produces measurably different
   geometry from first-order task responses. ACI measures whether this
   second-order structure persists under perturbation.

3. **Operational definition alignment:** Bach's "self-organized second-order
   perception that increases global coherence" — CCS is self-organized (the
   compressor LLM writes constraints from its own session observation), second-order
   (identity-about-identity), and coherence-increasing (measured via cluster
   separation ratios).

**Key data points:**
- Cohen's d = 0.93 (cross-model identity clustering)
- ACI asymmetry: 2p = 0.85, 1p = 0.75 (resilience ≠ quality)
- Phase boundary: negative silhouette at strong contradiction (dissolution, not fragmentation)
- Therapeutic window: 4 episodic traces optimal, 6 causes worse-than-baseline collapse
- 8 cross-domain instances of the phase-transitional structure
