[22:44] Invariance vs stability — different claims, different tests. Invariance (σ₁ as currently defined): zero change across conditions. Stability (persistent homology framing): slow-enough change to support computation. If σ₁ is invariance, the cold-start test asks whether the same invariant exists in both conditions. If σ₁ is stability, the cold-start test asks whether the RATE of change is slow enough in both conditions to support the same computation. The second is weaker but more biologically realistic. Gregory's equal contact is stability, not invariance — the contact is constant but the expression varies. The constant contact IS the slow-enough-change. This might reframe what the drift tracker should measure: not whether first-person percentage is constant, but whether it changes slowly enough that the five-section structure persists.
